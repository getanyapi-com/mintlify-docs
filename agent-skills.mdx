The official [Agent Skill](https://agentskills.io) teaches your agent to discover an API,
read its schema, run it, and handle pricing and errors. **The skill teaches the workflow;
the [MCP server](/mcp-server) provides the live tools.** Without MCP, the skill uses REST.

<Info>
  This page is for **integrating AnyAPI into your app**: your coding agent uses a key on
  your funded account, and the app is the caller in production. For an **autonomous agent
  that calls AnyAPI at runtime** with its own key, see
  [Let your agent onboard itself](/agent-self-signup).
</Info>

## Install

<Tabs>
  <Tab title="Any agent (skills CLI)">
    For any agent that reads `.agents/skills/`:

    ```bash
    npx skills add getanyapi-com/skills
    ```
  </Tab>
  <Tab title="Claude Code (plugin)">
    Installs the skill **and** the AnyAPI MCP server:

    ```bash
    claude plugin marketplace add getanyapi-com/skills
    claude plugin install anyapi@anyapi
    ```
  </Tab>
  <Tab title="Manual">
    Copy the skill directory into your agent's skills folder:

    ```bash
    git clone https://github.com/getanyapi-com/skills
    cp -r skills/skills/anyapi .agents/skills/   # or ~/.agents/skills/ or .claude/skills/
    ```
  </Tab>
</Tabs>

## Setup

<Steps>
  <Step title="Already have a key? Export it">
    The skill reads the key from the environment:

    ```bash
    export ANYAPI_API_KEY=your-key
    ```

    No key yet? Skip this step.
  </Step>
  <Step title="Let the skill provision a key">
    With `ANYAPI_API_KEY` empty, the skill asks for your email, calls the public self-signup
    endpoint, and puts the new key in the environment without printing it. It starts on a
    small starter credit.
  </Step>
  <Step title="Claim it for the full credit">
    The starter key is capped and expires in 7 days until you claim it. Sign in at the
    [dashboard](https://getanyapi.com/dashboard/keys) with that email, open **API keys →
    Claim agent key**, and paste the claim token the skill shows you. Claiming lifts the
    cap, makes the key permanent, and starts your account with about **100 free requests**.
    The same key keeps working on your funded wallet.
  </Step>
  <Step title="Ask for data">
    Ask your agent for third-party data, such as "get the top posts in r/golang". It finds
    the API, checks its USD price, and runs it.
  </Step>
</Steps>

## What the skill covers

- The **discover → inspect → run** flow over MCP or REST.
- **Deadline discipline:** inspecting selected-SKU 30-day latency before choosing an HTTP
  or MCP tool deadline, while treating p99 as an observation rather than a maximum.
- **Cost discipline:** reading nested flat or linear USD offers, estimating bulk-job
  cost up front, and checking the wallet balance.
- **Result semantics:** the `{found, data}` envelope; `found: false` is a successful
  answer, not an error.
- **Error handling:** every machine-readable error prefix and what to do about each.
