Search TikTok's public Ads Library by keyword or advertiser (advertiser, title, audience band, run dates, library link, and video).

This page is the seller-facing summary of one catalog API, `tiktok.ad_library_search`. The transport rules that apply to every API a seller serves - signed requests, the response envelope, timeouts, and body limits - are on [the operator endpoint contract](/sell/operator-endpoint-contract).

## The price you compete with

AnyAPI publishes this API from **$0.80 per 1,000 requests**. That is the price a buyer sees today, so it is the price your endpoint has to come in under to win traffic.

This API takes no input fields.

## The response your endpoint must return

| Field | Type | Always present | What it means |
| --- | --- | --- | --- |
| `data` | null or object | yes |  |
| `data.ads` | array | yes |  |
| `data.ads[].adId` | string | yes | TikTok ad id. |
| `data.ads[].adTitle` | string | yes | Ad title as shown in TikTok's ad library. |
| `data.ads[].brandName` | string | yes | Advertiser name on the ad. |
| `data.ads[].coverUrl` | string | yes | Cover image URL of the ad's first video. |
| `data.ads[].estimatedAudience` | string | yes | Audience size band TikTok publishes for the ad, for example "100K-200K". |
| `data.ads[].firstShownUtc` | integer | no | UTC epoch timestamp in seconds (Unix time) when TikTok first showed the ad. Multiply by 1000 for a JS Date in milliseconds. |
| `data.ads[].format` | string or null | no | TikTok's creative format code for the ad, as the ad library reports it. Null when the serving source does not report it. |
| `data.ads[].lastShownUtc` | integer | no | UTC epoch timestamp in seconds (Unix time) when TikTok last showed the ad. Multiply by 1000 for a JS Date in milliseconds. |
| `data.ads[].status` | string or null | no | TikTok's audit status code for the ad, as the ad library reports it. Null when the serving source does not report it. |
| `data.ads[].url` | string | no | Link to the ad's detail page in TikTok's public Ads Library. |
| `data.ads[].videoUrl` | string | yes | Playable URL of the ad's first video. |
| `data.hasMore` | boolean | yes |  |
| `data.nextCursor` | string or null | yes | Opaque cursor for the next page of ads, or null when this lane has no more. Pass it back as cursor to continue. |
| `data.total` | integer | yes |  |
| `found` | boolean | yes |  |

Extra fields are kept, missing declared fields fail.

## Fields that must never come back empty

- `adId`
- `adTitle`
- `ads`
- `coverUrl`
- `videoUrl`

The repository marks these fields as ones every source must be able to fill. An empty value is only correct when the entity itself genuinely has nothing there.

## Not found, and how it differs from empty

When the entity does not exist, answer 2xx with the not-found shape:

```json
{
  "found": false,
  "data": null
}
```

An empty list is not a not-found: when the entity exists and has nothing to return, answer 2xx with `found: true` and an empty `ads` array.

This output schema declares no `reason` field, so `found: false` is the whole not-found answer.
