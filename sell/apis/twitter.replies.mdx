Fetch the replies to any X (Twitter) post URL as structured records: author, text, and engagement. An empty result is valid and does not assert whether the target post exists.

This page is the seller-facing summary of one catalog API, `twitter.replies`. The transport rules that apply to every API a seller serves - signed requests, the response envelope, timeouts, and body limits - are on [the operator endpoint contract](/sell/operator-endpoint-contract).

## The price you compete with

AnyAPI publishes this API from **$0.50 per 1,000 requests**. That is the price a buyer sees today, so it is the price your endpoint has to come in under to win traffic.

## The response your endpoint must return

| Field | Type | Always present | What it means |
| --- | --- | --- | --- |
| `data` | null or object | yes |  |
| `data.conversationId` | string | no | Id of the conversation the reply belongs to, as a string. |
| `data.items` | array | yes | Reply records for the requested post. |
| `data.items[].authorHandle` | string | no | Screen name / handle of the reply's author, without the @ prefix. |
| `data.items[].authorName` | string | no | Display name of the reply's author. Empty when the upstream omits it. |
| `data.items[].createdUtc` | number | yes | UTC epoch timestamp in seconds (Unix time). Multiply by 1000 for a JS Date in milliseconds. |
| `data.items[].id` | string | yes | The reply's numeric tweet ID, as a string. |
| `data.items[].likeCount` | integer | no | Number of likes on this reply. |
| `data.items[].media` | array | no | Photo, video, and GIF attachments on the post. Empty when the post has none. |
| `data.items[].media[].height` | integer | no | Pixel height of the media item, when the lane reports it. |
| `data.items[].media[].type` | string | yes | One of photo, video, or gif. |
| `data.items[].media[].url` | string | yes | Image URL. For a video or GIF this is the poster/thumbnail frame. X media URLs on pbs.twimg.com are publicly fetchable without authentication; append ?name=orig for the full-resolution original. |
| `data.items[].media[].videoUrl` | string | no | Playable video file URL. Present only for video and gif items. |
| `data.items[].media[].width` | integer | no | Pixel width of the media item, when the lane reports it. |
| `data.items[].quoteCount` | integer | no | Number of quote tweets of this reply. |
| `data.items[].replyCount` | integer | no | Number of replies to this reply. |
| `data.items[].repostCount` | integer | no | Number of reposts/retweets of this reply. |
| `data.items[].text` | string | yes | The reply's text. Empty for media-only replies with no text. |
| `data.items[].url` | string | yes | Canonical x.com URL of the reply, with tracking query params stripped. |
| `data.items[].viewCount` | integer | no | Number of views of this reply. |
| `found` | boolean | yes | Whether the provider returned a reply result. An empty items array is valid and may mean the post has no replies or the target could not be resolved. |

Extra fields are kept, missing declared fields fail.

## Fields that must never come back empty

- `id`
- `items`
- `url`

The repository marks these fields as ones every source must be able to fill. An empty value is only correct when the entity itself genuinely has nothing there.

## Not found, and how it differs from empty

When the entity does not exist, answer 2xx with the not-found shape:

```json
{
  "found": false,
  "data": null
}
```

An empty list is not a not-found: when the entity exists and has nothing to return, answer 2xx with `found: true` and an empty `items` array.

This output schema declares no `reason` field, so `found: false` is the whole not-found answer.

## Example request

```json
{
  "url": "https://x.com/jack/status/20"
}
```

The compatibility checks fire the schema's example at your endpoint. After that, your answers are graded against what the currently serving source returned for the same real customer inputs.

## Behavior

- The input is the full post URL, and the numeric post id is read out of its /status/&lt;id&gt; segment.
- An empty items array is a valid answer and says nothing about whether the post exists, so it is never reported as a failure.
- limit is 1 to 40.
- Every reply carries id, url, text and createdUtc, and text is empty for a reply that is media only.
