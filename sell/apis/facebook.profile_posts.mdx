List a Facebook page's recent posts by URL or page id with cursor pagination (text, author, publication time, permalink).

This page is the seller-facing summary of one catalog API, `facebook.profile_posts`. The transport rules that apply to every API a seller serves - signed requests, the response envelope, timeouts, and body limits - are on [the operator endpoint contract](/sell/operator-endpoint-contract).

## The price you compete with

AnyAPI publishes this API from **$1.20 per 1,000 requests**. That is the price a buyer sees today, so it is the price your endpoint has to come in under to win traffic.

## The request your endpoint receives

This API takes no input fields.

## The response your endpoint must return

| Field | Type | Always present | What it means |
| --- | --- | --- | --- |
| `data` | null or object | yes |  |
| `data.nextCursor` | string or null | yes | Opaque cursor for the next page of posts, or null when this lane has no more. Pass it back as cursor to continue. |
| `data.posts` | array | yes |  |
| `data.posts[].author` | string | yes |  |
| `data.posts[].authorId` | string | no | Numeric Facebook id of the page or profile that posted, as a string. |
| `data.posts[].comments` | integer | no | Comment count on the post. |
| `data.posts[].createdUtc` | number | yes | UTC epoch timestamp in seconds (Unix time). Multiply by 1000 for a JS Date in milliseconds. |
| `data.posts[].id` | string | yes |  |
| `data.posts[].image` | string | no | Preview image or video thumbnail URL for the post. |
| `data.posts[].likes` | integer | no | Total reaction count on the post. |
| `data.posts[].media` | array | no | Photo, video, and GIF attachments on the post. Empty when the post has none. |
| `data.posts[].media[].height` | integer | no | Pixel height of the media item, when the lane reports it. |
| `data.posts[].media[].type` | string | yes | One of photo, video, or gif. |
| `data.posts[].media[].url` | string | yes | Image URL. For a video or GIF this is the poster/thumbnail frame. |

| `data.posts[].media[].width` | integer | no | Pixel width of the media item, when the lane reports it. |
| `data.posts[].reactions` | object | yes | Reaction counts on the post, broken down by reaction type. |
| `data.posts[].reactions.angry` | integer | no | Angry reactions. |

## Fields that must never come back empty

- `author`
- `createdUtc`
- `id`
- `posts`
- `text`
- `url`

The repository marks these fields as ones every source must be able to fill. An empty value is only correct when the entity itself genuinely has nothing there.

## Not found, and how it differs from empty

When the entity does not exist, answer 2xx with the not-found shape:

```json
{
  "found": false,
  "data": null
}
```

An empty list is not a not-found: when the entity exists and has nothing to return, answer 2xx with `found: true` and an empty `posts` array.

This output schema declares no `reason` field, so `found: false` is the whole not-found answer.

## Example request

```json
{
  "url": "https://www.facebook.com/nike"
}
```
