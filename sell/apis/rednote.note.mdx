Look up a RedNote (Xiaohongshu) note by note ID and return normalized note details.

This page is the seller-facing summary of one catalog API, `rednote.note`. The transport rules that apply to every API a seller serves - signed requests, the response envelope, timeouts, and body limits - are on [the operator endpoint contract](/sell/operator-endpoint-contract).

## The price you compete with

AnyAPI publishes this API from **$12.00 per 1,000 requests**. That is the price a buyer sees today, so it is the price your endpoint has to come in under to win traffic.

## The response your endpoint must return

| Field | Type | Always present | What it means |
| --- | --- | --- | --- |
| `data` | null or object | yes | The note record, or null when nothing was found. |
| `data.authorImage` | string | no | URL of the author's avatar. |
| `data.authorNickname` | string | no | Display name of the note author. |
| `data.authorRedId` | string | no | Author's public RedNote ID. |
| `data.authorUserId` | string | no | Identifier of the note author. |
| `data.authorVerified` | boolean | no | Whether the author carries RedNote's official verification. |
| `data.collectCount` | integer | no | Number of times the note was collected. |
| `data.commentCount` | integer | no | Number of comments on the note. |
| `data.createdUtc` | number | no | UTC epoch timestamp in seconds (Unix time). Multiply by 1000 for a JS Date in milliseconds. |
| `data.description` | string | no | Note body text. |
| `data.image` | string | no | URL of the note cover image. |
| `data.language` | string | no | Detected language of the note. |
| `data.likeCount` | integer | no | Number of likes on the note. |
| `data.location` | string | no | Location the note was posted from, as RedNote reports it. |
| `data.noteId` | string | yes | Note identifier. |
| `data.shareCount` | integer | no | Number of times the note was shared. |
| `data.title` | string | no | Note title. |
| `data.type` | string | no | Note type, e.g. "normal" or "video". |
| `data.updatedUtc` | number | no | UTC epoch timestamp in seconds (Unix time). Multiply by 1000 for a JS Date in milliseconds. |
| `data.url` | string | no | Canonical URL of the note. |
| `found` | boolean | yes | True when the note was found; false when the lookup returned nothing. |

Extra fields are kept, missing declared fields fail.

## Fields that must never come back empty

- `authorNickname`
- `authorRedId`
- `authorUserId`
- `createdUtc`
- `description`
- `image`
- `language`
- `noteId`
- `title`
- `type`
- `updatedUtc`
- `url`

The repository marks these fields as ones every source must be able to fill. An empty value is only correct when the entity itself genuinely has nothing there.

## Not found, and how it differs from empty

When the entity does not exist, answer 2xx with the not-found shape:

```json
{
  "found": false,
  "data": null
}
```

This API says what comes back as not found:

> True when the note was found; false when the lookup returned nothing.

Follow that rule: where it calls a case not found, answer with the not-found shape above.

This output schema declares no `reason` field, so `found: false` is the whole not-found answer.
