title: "APIs open to sellers"
description: "The catalog APIs you can register an endpoint for yourself, with the published price each one competes against."
---

42 catalog APIs are open for self-serve seller registration. Pick one, build an endpoint for it, and register it from [Sell APIs](https://getanyapi.com/dashboard/sell/endpoints). Each page below gives the request, the response, and what the grader expects.

For any other API in the catalog, email [support@getanyapi.com](mailto:support@getanyapi.com) and we will open it with you.

The "published from" column is the price a buyer pays today, per 1,000 requests, and so the price your endpoint competes with.
