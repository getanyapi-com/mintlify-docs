List an Instagram account's reels by handle with cursor pagination (caption, plays, likes, comments).

This page is the seller-facing summary of one catalog API, `instagram.user_reels`. The transport rules that apply to every API a seller serves - signed requests, the response envelope, timeouts, and body limits - are on [the operator endpoint contract](/sell/operator-endpoint-contract).

## The price you compete with

AnyAPI publishes this API from **$0.80 per 1,000 requests**. That is the price a buyer sees today, so it is the price your endpoint has to come in under to win traffic.

This API takes no input fields.

| `data.reels[].durationSeconds` | number | yes | Reel duration in seconds. |

| `data.reels[].id` | string | yes | Instagram media id. |

| `data.reels[].likes` | integer | yes |  |

| `data.reels[].locationLng` | number or null | no | Longitude of the tagged location, in decimal degrees. Null when the serving source does not report it. |

| `data.reels[].media` | array | no | Photo, video, and GIF attachments on the post. Empty when the post has none. |
| `data.reels[].media[].height` | integer | no | Pixel height of the media item, when the lane reports it. |
| `data.reels[].media[].type` | string | yes | One of photo, video, or gif. |

| `data.reels[].media[].videoUrl` | string | no | Playable video file URL. Present only for video and gif items. |
| `data.reels[].media[].width` | integer | no | Pixel width of the media item, when the lane reports it. |
| `data.reels[].mentions` | array | no | Accounts @mentioned in the caption, each including its leading @. |
| `data.reels[].paidPartnership` | boolean or null | no | Whether the post is tagged as a paid partnership. Null when the serving source does not report it. |
| `data.reels[].productType` | string or null | no | Instagram's own surface label for the post, such as feed, clips or carousel_container. Null when the serving source does not report it. |
| `data.reels[].reshares` | integer or null | no | Number of times the post has been reshared, when Instagram reports it. Null when the serving source does not report it. |
| `data.reels[].shortcode` | string | yes |  |
| `data.reels[].soundAuthor` | string or null | no | Credited artist of a licensed track, or the username of the account whose original audio it is. Absent when the post has no sound. Null when the serving source does not report it. |

| `data.reels[].userId` | string | no | Instagram user id of the posting account. |
| `data.reels[].username` | string | yes | Username of the account that posted the reel. A reels tab includes collaborator reels, so this is not always the requested handle. |
| `data.reels[].verified` | boolean | yes | True when the posting account is verified. |
| `data.reels[].views` | integer | yes |  |

## Fields that must never come back empty

- `caption`
- `hashtags`
- `id`
- `mentions`
- `reels`
- `shortcode`
- `username`

The repository marks these fields as ones every source must be able to fill. An empty value is only correct when the entity itself genuinely has nothing there.

## Not found, and how it differs from empty

When the entity does not exist, answer 2xx with the not-found shape:

```json
{
  "found": false,
  "data": null
}
```

An empty list is not a not-found: when the entity exists and has nothing to return, answer 2xx with `found: true` and an empty `reels` array.

This output schema declares no `reason` field, so `found: false` is the whole not-found answer.
