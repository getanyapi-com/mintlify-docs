List the ads a company is running from the Google Ads Transparency Center by domain or advertiser ID (creative ID, format, ad URL, and first/last shown dates) with cursor pagination.

This page is the seller-facing summary of one catalog API, `google_ads.company_ads`. The transport rules that apply to every API a seller serves - signed requests, the response envelope, timeouts, and body limits - are on [the operator endpoint contract](/sell/operator-endpoint-contract).

## The price you compete with

AnyAPI publishes this API from **$0.73 per 1,000 requests**. That is the price a buyer sees today, so it is the price your endpoint has to come in under to win traffic.

## The request your endpoint receives

| Field | Type | Required | What it means |
| --- | --- | --- | --- |
| `advertiserId` | string | no | Advertiser ID. Provide either domain or advertiserId. |
| `cursor` | string | no | Opaque pagination cursor from a previous response's nextCursor. |
| `domain` | string | no | Company domain (e.g. "lululemon.com"). Provide either domain or advertiserId. |
| `endDate` | string | no | Only return ads first shown on or before this date, format YYYY-MM-DD (e.g. 2024-12-31). |
| `format` | string | no | Ad format filter. One of: `text`, `image`, `video`. |
| `platform` | string | no | Platform filter. One of: `google_maps`, `google_play`, `google_search`, `google_shopping`, `youtube`. |
| `region` | string | no | Two-letter country code to scope results (e.g. "US", "AU"). |
| `startDate` | string | no | Only return ads first shown on or after this date, format YYYY-MM-DD (e.g. 2024-01-01). |
| `topic` | string | no | Search topic. "political" requires a region. One of: `all`, `political`. |

| Field | Type | Always present | What it means |
| --- | --- | --- | --- |
| `data` | null or object | yes |  |
| `data.ads` | array | yes |  |
| `data.ads[].adUrl` | string | yes |  |

| `data.ads[].advertiserName` | string | yes |  |
| `data.ads[].creativeId` | string | yes |  |
| `data.ads[].domain` | string | no | Registrable domain the ad links to. |
| `data.ads[].firstShown` | string | yes | ISO 8601 date. |
| `data.ads[].format` | string | yes |  |
| `data.ads[].imageUrl` | string | yes |  |
| `data.ads[].lastShown` | string | yes | ISO 8601 date. |
| `data.adsEstimate` | integer | yes | Estimated total number of ads. |
| `data.nextCursor` | string or null | yes | Opaque cursor for the next page of ads, or null when this lane has no more. Pass it back as cursor to continue. |

## Fields that must never come back empty

- `adUrl`
- `ads`
- `advertiserId`
- `advertiserName`
- `creativeId`
- `format`

The repository marks these fields as ones every source must be able to fill. An empty value is only correct when the entity itself genuinely has nothing there.

## Not found, and how it differs from empty

When the entity does not exist, answer 2xx with the not-found shape:

```json
{
  "found": false,
  "data": null
}
```

An empty list is not a not-found: when the entity exists and has nothing to return, answer 2xx with `found: true` and an empty `ads` array.

This output schema declares no `reason` field, so `found: false` is the whole not-found answer.
