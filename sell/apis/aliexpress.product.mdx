Look up one AliExpress product by id and get its price, original price, rating, reviews count, images, options, variants with stock, specifications, store, ship-from country and delivery estimate in one normalized response.

This page is the seller-facing summary of one catalog API, `aliexpress.product`. The transport rules that apply to every API a seller serves - signed requests, the response envelope, timeouts, and body limits - are on [the operator endpoint contract](/sell/operator-endpoint-contract).

## The price you compete with

AnyAPI publishes this API from **$0.90 per 1,000 requests**. That is the price a buyer sees today, so it is the price your endpoint has to come in under to win traffic.

## The request your endpoint receives

| Field | Type | Required | What it means |
| --- | --- | --- | --- |
| `country` | string | no | Ship-to country as a 2-letter ISO code, e.g. US or DE. It changes prices, stock and the delivery estimate. Default `"US"`. |
| `currency` | string | no | Price currency as a 3-letter ISO code, e.g. USD or EUR. Default `"USD"`. |
| `productId` | string | yes | AliExpress product id, the number in the product URL (https://www.aliexpress.com/item/&lt;id&gt;.html), e.g. 3256807039224587. The AliExpress Search SKU returns it as productId. |
| `requireFields` | array | no | Optional; omit it and routing is unchanged, with the cheapest source serving. Name the output fields this request must be able to return, for example `video`, and it is served only by a source that returns every one of them. Fields you do not name are still returned whenever the serving source has them. This can raise your price: when the cheapest source cannot return a named field, a dearer source serves, and you are quoted and charged its price. Naming a combination that no single source returns together is refused as invalid input, with no charge. |

## The response your endpoint must return

| Field | Type | Always present | What it means |
| --- | --- | --- | --- |
| `data` | null or object | yes | Product wrapper, or null when AliExpress has no product with that id. |
| `data.items` | array | yes | Product detail records (one per requested product id). |
| `data.items[].currency` | string or null | no | Price currency code, e.g. "USD", or null when no price is shown. |
| `data.items[].deliveryDaysMax` | integer or null | no | Most days the default shipping option takes to the requested country, or null when not reported. |
| `data.items[].deliveryDaysMin` | integer or null | no | Fewest days the default shipping option takes to the requested country, or null when not reported. |
| `data.items[].freeShipping` | boolean or null | no | True when the default shipping option to the requested country costs nothing after AliExpress's buyer promotions, or null when the serving source does not report it. |
| `data.items[].images` | array | no | Product image URLs, primary first. |
| `data.items[].isTopRatedSeller` | boolean or null | no | True when AliExpress marks the store as a top-rated seller, or null when not reported. |
| `data.items[].options` | array | no | The choices a buyer picks from, e.g. Color and Size, each with its values. |
| `data.items[].options[].name` | string | no | Option name as AliExpress shows it, e.g. "Color". |
| `data.items[].options[].values` | array | no | Values a buyer can pick, e.g. ["green", "Purple"]. |
| `data.items[].originalPrice` | number or null | no | Price of the default variant before the current discount, or null when not shown. |
| `data.items[].price` | number or null | no | Current price of the default variant in the requested currency (the lowest variant price when the page shows a range), or null when not shown. |
| `data.items[].productId` | string | yes | AliExpress product id. |
| `data.items[].quantityAvailable` | integer or null | no | Units in stock across all variants, or null when not reported. |
| `data.items[].rating` | number or null | no | Average customer rating, 0-5, or null when the product is unrated. |
| `data.items[].returnPolicy` | string or null | no | The returns promise AliExpress shows on the product, e.g. "Free returns within 90 days", or null when the serving source does not report it. |
| `data.items[].reviewsCount` | integer or null | no | Number of customer reviews, or null when not reported. |
| `data.items[].sellerCountry` | string or null | no | Country the store is registered in, as AliExpress names it, e.g. "China", or null when not reported. |
| `data.items[].sellerFeedbackCount` | integer or null | no | Number of buyer feedback ratings the store has received, or null when not reported. |
| `data.items[].sellerFeedbackPercent` | number or null | no | Share of the store's buyer feedback that is positive, as a percentage, e.g. 95.9, or null when not reported. |
| `data.items[].sellerLevel` | string or null | no | The store's AliExpress seller level code, e.g. "25-s", or null when not reported. |
| `data.items[].sellerOpenedUtc` | number or null | no | UTC epoch timestamp in seconds (Unix time). Multiply by 1000 for a JS Date in milliseconds. The day the store opened on AliExpress, as midnight UTC of that date; null when not reported. |
| `data.items[].sellerScore` | integer or null | no | The store's AliExpress feedback score, the points AliExpress shows beside the store, or null when not reported. |
| `data.items[].shipFrom` | string or null | no | Country the default shipping option ships from, as AliExpress names it, e.g. "China", or null when not reported. |
| `data.items[].shippingCost` | number or null | no | Shipping cost of the default option to the requested country, in the requested currency, or null when not reported or the serving source does not report it in that currency. AliExpress applies buyer promotions to it, so sources can differ. |
| `data.items[].soldCount` | integer or null | no | Units sold, read from AliExpress's rounded label, so "4,000+ sold" comes back as 4000; null when not shown. |
| `data.items[].specifications` | array | no | The seller's specifications table, one name and value per row. |
| `data.items[].specifications[].name` | string | no | Attribute name as the seller lists it, e.g. "Material". |
| `data.items[].specifications[].value` | string | no | Attribute value as the seller lists it. |
| `data.items[].storeId` | string or null | no | Storefront number of the store, the digits in https://www.aliexpress.com/store/&lt;id&gt;, or null when not reported. |
| `data.items[].storeName` | string or null | no | Name of the store selling the product, or null when not reported. |
| `data.items[].title` | string | yes | Product title. |
| `data.items[].url` | string | yes | AliExpress product page URL with tracking query parameters removed. |
| `data.items[].variants` | array | no | One entry per purchasable combination of options. |
| `data.items[].variants[].attributes` | object or null | no | The option values that make up this variant, keyed by option name, e.g. &#123;"Color": "Purple", "Size": "XL"&#125;, or null when the serving source does not report them. |
| `data.items[].variants[].image` | string or null | no | Picture of this variant, or null when it has none or the serving source does not report it. |
| `data.items[].variants[].inStock` | boolean or null | no | True when this variant can be bought now, or null when not reported. |
| `data.items[].variants[].originalPrice` | number or null | no | Price of this variant before the current discount, or null when not reported. |
| `data.items[].variants[].price` | number or null | no | Current price of this variant, or null when the serving source does not report it. |
| `data.items[].variants[].quantityAvailable` | integer or null | no | Units of this variant in stock, or null when not reported. |
| `data.items[].variants[].skuId` | string | no | AliExpress id of this variant. |
| `data.items[].video` | string or null | no | Product video URL (MP4), or null when the product has none or the serving source does not report it. |
| `data.items[].wishlistCount` | integer or null | no | Number of shoppers who added the product to their wish list, or null when the serving source does not report it. |
| `found` | boolean | yes | True when the product was found. |

Extra fields are kept, missing declared fields fail.

## Not found, and how it differs from empty

When the entity does not exist, answer 2xx with the not-found shape:

```json
{
  "found": false,
  "data": null
}
```

An empty list is not a not-found: when the entity exists and has nothing to return, answer 2xx with `found: true` and an empty `items` array.

This output schema declares no `reason` field, so `found: false` is the whole not-found answer.
