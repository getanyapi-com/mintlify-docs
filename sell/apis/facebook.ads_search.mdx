Search the Meta Ad Library by keyword and get matching ads (advertiser, creative text, CTA, platforms, and run dates) with cursor pagination.

This page is the seller-facing summary of one catalog API, `facebook.ads_search`. The transport rules that apply to every API a seller serves - signed requests, the response envelope, timeouts, and body limits - are on [the operator endpoint contract](/sell/operator-endpoint-contract).

## The price you compete with

AnyAPI publishes this API from **$1.20 per 1,000 requests**. That is the price a buyer sees today, so it is the price your endpoint has to come in under to win traffic.

## The request your endpoint receives

| Field | Type | Required | What it means |
| --- | --- | --- | --- |
| `adType` | string | no | Restrict to all ads (default) or only political and issue ads. One of: `all`, `political_and_issue_ads`. |
| `country` | string | no | Two-letter country code to scope results. Omit for all countries. |
| `cursor` | string | no | Opaque pagination cursor from a previous response's nextCursor. |
| `endDate` | string | no | Filter to ads with impressions on or before this date, in YYYY-MM-DD format. |
| `mediaType` | string | no | Creative media type filter. One of: `ALL`, `IMAGE`, `VIDEO`, `MEME`, `IMAGE_AND_MEME`, `NONE`. |
| `query` | string | yes | Keyword to search the Meta Ad Library for (e.g. "protein powder"). |
| `searchType` | string | no | Match mode for the query: loose keyword match (keyword_unordered, the default) or exact phrase (keyword_exact_phrase). One of: `keyword_unordered`, `keyword_exact_phrase`. |
| `sortBy` | string | no | Sort order: impressions (highest first, the default) or recent (most recent). One of: `impressions`, `recent`. |
| `startDate` | string | no | Filter to ads with impressions on or after this date, in YYYY-MM-DD format. |
| `status` | string | no | Ad status filter. One of: `ALL`, `ACTIVE`, `INACTIVE`. Default `"ACTIVE"`. |

## The response your endpoint must return

| Field | Type | Always present | What it means |
| --- | --- | --- | --- |
| `data` | null or object | yes |  |
| `data.ads` | array | yes |  |
| `data.ads[].active` | boolean | yes |  |
| `data.ads[].adCount` | integer | yes | Number of ads in this campaign (collation count). |
| `data.ads[].caption` | string | no | Caption line of the ad creative, usually the advertiser's display domain. |
| `data.ads[].categories` | array | no | Ad Library categories the ad is filed under. |
| `data.ads[].ctaText` | string | yes |  |
| `data.ads[].ctaType` | string | yes |  |
| `data.ads[].displayFormat` | string | yes |  |
| `data.ads[].endDate` | integer | yes | Epoch seconds. |
| `data.ads[].id` | string | yes | Ad Library archive ID. |
| `data.ads[].isReshared` | boolean | no | Whether the ad creative is a reshare of another post. |
| `data.ads[].linkDescription` | string | no | Description text shown under the ad's link. |
| `data.ads[].linkUrl` | string | yes |  |
| `data.ads[].media` | array | no | Creative attached to the ad: one element per image, video, or carousel card, in the order the ad presents them. Empty when the ad has none. |
| `data.ads[].media[].height` | integer | no | Pixel height of the media item, when the lane reports it. |
| `data.ads[].media[].type` | string | yes | One of photo, video, or gif. |
| `data.ads[].media[].url` | string | yes | Image URL. For a video or GIF this is the poster/thumbnail frame. |
| `data.ads[].media[].videoUrl` | string | no | Playable video file URL. Present only for video and gif items. |
| `data.ads[].media[].width` | integer | no | Pixel width of the media item, when the lane reports it. |
| `data.ads[].pageCategories` | array | no | Categories Facebook lists the advertising page under. |
| `data.ads[].pageDeleted` | boolean | no | Whether the advertising page has been deleted. |
| `data.ads[].pageId` | string | yes |  |
| `data.ads[].pageLikes` | integer | no | Like count of the advertising page. |
| `data.ads[].pageName` | string | yes |  |
| `data.ads[].pageProfilePicture` | string | no | Profile picture of the advertising page. This is the advertiser's identity image, not ad creative. |
| `data.ads[].pageUrl` | string | no | Canonical Facebook URL of the advertising page. |
| `data.ads[].platforms` | array | yes |  |
| `data.ads[].sourceUrl` | string | yes | Inspectable Meta Ad Library URL for this ad. |
| `data.ads[].startDate` | integer | yes | Epoch seconds. |
| `data.ads[].text` | string | yes | Ad body text. |
| `data.ads[].title` | string | yes |  |
| `data.nextCursor` | string or null | yes | Opaque cursor for the next page of ads, or null when this lane has no more. Pass it back as cursor to continue. |

## Fields that must never come back empty

- `ctaText`
- `ctaType`
- `displayFormat`
- `id`
- `linkUrl`
- `pageId`
- `pageName`
- `platforms`
- `sourceUrl`
- `startDate`
- `text`
- `title`

The repository marks these fields as ones every source must be able to fill. An empty value is only correct when the entity itself genuinely has nothing there.

## Not found, and how it differs from empty

When the entity does not exist, answer 2xx with the not-found shape:

```json
{
  "found": false,
  "data": null
}
```

An empty list is not a not-found: when the entity exists and has nothing to return, answer 2xx with `found: true` and an empty `ads` array.

This output schema declares no `reason` field, so `found: false` is the whole not-found answer.
