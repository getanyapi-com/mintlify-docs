Fetch a YouTube video or Short transcript with timed segments and its provenance: whether the words are creator-written captions or machine speech recognition.

This page is the seller-facing summary of one catalog API, `youtube.video_transcript_full`. The transport rules that apply to every API a seller serves - signed requests, the response envelope, timeouts, and body limits - are on [the operator endpoint contract](/sell/operator-endpoint-contract).

## The price you compete with

AnyAPI publishes this API from **$2.00 per 1,000 requests**. That is the price a buyer sees today, so it is the price your endpoint has to come in under to win traffic.

## The request your endpoint receives

| Field | Type | Required | What it means |
| --- | --- | --- | --- |
| `captionKind` | string | no | Which caption track to accept: "manual" only creator-written captions, "automatic" only YouTube's speech recognition, "any" whichever exists. One of: `manual`, `automatic`, `any`. Default `"any"`. |
| `language` | string | no | Preferred caption language code (e.g. "en", "es"). Defaults to English. If the video has no captions in that language, you get the transcript in another language the video has; the `language` field in the result says which. With `captionKind` set to "manual" or "automatic", no other language is returned. |
| `requireFields` | array | no | Optional; omit it and routing is unchanged, with the cheapest source serving. Name the output fields this request must be able to return, for example `likes`, and it is served only by a source that returns every one of them. Fields you do not name are still returned whenever the serving source has them. This can raise your price: when the cheapest source cannot return a named field, a dearer source serves, and you are quoted and charged its price. A named field can still be absent on a transcript that genuinely lacks it. Naming a combination that no single source returns together is refused as invalid input, with no charge. |
| `url` | string | yes | YouTube video or Short URL (e.g. "https://www.youtube.com/watch?v=dQw4w9WgXcQ" or "https://www.youtube.com/shorts/Fir1x9cw2vg"). |

## The response your endpoint must return

| Field | Type | Always present | What it means |
| --- | --- | --- | --- |
| `data` | null or object | yes |  |
| `data.authorId` | string | no | YouTube channel ID of the publishing channel. |
| `data.authorUrl` | string | no | Canonical URL of the publishing channel, tracking query parameters stripped. |
| `data.category` | string | no | YouTube category the video is filed under, for example "Music". |
| `data.channel` | string | no | Channel name that published the video. |
| `data.createdUtc` | number | no | UTC epoch timestamp in seconds (Unix time). Multiply by 1000 for a JS Date in milliseconds. |
| `data.description` | string | no | Full video description text. |
| `data.durationSeconds` | number | no | Video duration in seconds. |
| `data.image` | string | no | URL of the video thumbnail image. |
| `data.isAiGenerated` | boolean or null | no | True when the words were recognized from the audio by the serving lane rather than read from any YouTube caption track, or null when the serving source does not say. |
| `data.isAutoGenerated` | boolean | yes | True when YouTube generated the caption track by speech recognition rather than the creator supplying it. Automatic captions carry recognition errors, especially on names and jargon. |
| `data.keywords` | array | no | Keywords the uploader tagged the video with. |
| `data.language` | string | yes | Caption language code (e.g. "en"). |
| `data.likes` | integer | no | Number of likes. |
| `data.segments` | array | no | Timed transcript segments in playback order. |
| `data.segments[].endSeconds` | number | yes | Segment end offset in seconds. |
| `data.segments[].startSeconds` | number | yes | Segment start offset in seconds. |
| `data.segments[].text` | string | yes | Text of this transcript segment. |
| `data.title` | string | no | Video title. |
| `data.transcript` | string | yes | Full transcript text, segments joined in playback order. |
| `data.url` | string | no | Watch URL of the video. |
| `data.videoId` | string | no | Unique identifier of the video. |
| `data.views` | integer | no | Number of views. |
| `found` | boolean | yes |  |

Extra fields are kept, missing declared fields fail.

## Fields that must never come back empty

- `isAutoGenerated`
- `language`
- `segments`
- `transcript`

The repository marks these fields as ones every source must be able to fill. An empty value is only correct when the entity itself genuinely has nothing there.

## Not found, and how it differs from empty

When the entity does not exist, answer 2xx with the not-found shape:

```json
{
  "found": false,
  "data": null
}
```

This output schema declares no `reason` field, so `found: false` is the whole not-found answer.

## Example request

```json
{
  "url": "https://www.youtube.com/watch?v=dQw4w9WgXcQ"
}
```

The registration tests send this example to your endpoint, with the API's other test inputs. After that, the real-request check sends your endpoint real past customer inputs, and an AI reviewer compares each answer with AnyAPI's own answer to the same input.
