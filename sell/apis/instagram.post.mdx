Fetch a single Instagram post or reel by URL (media URLs, like count, owner, type) as normalized JSON. Turn on hostVideo to also get the post's video on a hosted MP4 link that plays without an Instagram session, charged as an extra on top of the price. If you want the spoken words as well, instagram.reel_transcript transcribes the same reel.

This page is the seller-facing summary of one catalog API, `instagram.post`. The transport rules that apply to every API a seller serves - signed requests, the response envelope, timeouts, and body limits - are on [the operator endpoint contract](/sell/operator-endpoint-contract).

## The price you compete with

AnyAPI publishes this API from **$0.50 per 1,000 requests**. That is the price a buyer sees today, so it is the price your endpoint has to come in under to win traffic.

## The request your endpoint receives

| Field | Type | Required | What it means |
| --- | --- | --- | --- |
| `hostVideo` | boolean | no | Set true to also get the post's video on a hosted MP4 link that plays without an Instagram session. The file is downloaded and stored for you, and the response adds `hostedUrl`, `expiresUtc` and `bytes`. It is charged as an extra on top of the price, and it never changes which source serves you: every source offers it at the same price. A post with no video, or a post that does not exist, is refused with no charge rather than billed for a file that cannot exist. Omit it and nothing is downloaded, nothing is stored, and nothing extra is charged. Default `false`. |
| `requireFields` | array | no | Optional; omit it and routing is unchanged, with the cheapest source serving. Name the output fields this request must be able to return, for example `plays`, and it is served only by a source that returns every one of them. Fields you do not name are still returned whenever the serving source has them. This can raise your price: when the cheapest source cannot return a named field, a dearer source serves, and you are quoted and charged its price. A named field can still be absent on a post that genuinely lacks it. Naming a combination that no single source returns together is refused as invalid input, with no charge. |
| `requirePlayCount` | boolean | no | Deprecated; send `requireFields: ["plays"]` instead, which does exactly the same thing. Set true to be served only by a source that reports a reel's play count. Omit it and routing is unchanged, with the cheapest source serving, which does not carry play counts, so `plays` is absent from its responses. This can raise your price: opting in routes to a source that reports the count, and you are quoted and charged its price. It stays accepted so callers that already send it keep working. |
| `url` | string | yes | Full Instagram post or reel URL, carrying the media shortcode: /p/, /reel/, /reels/, or /tv/. A profile URL such as https://www.instagram.com/username names no post, so it is rejected instead of charged for an empty result - send that account's handle to instagram.profile, or its posts to instagram.user_posts. |

## The response your endpoint must return

| Field | Type | Always present | What it means |
| --- | --- | --- | --- |
| `data` | null or object | yes |  |
| `data.altText` | string or null | no | Instagram's generated accessibility description of the media. Null when this source does not report it. |
| `data.audioId` | string or null | no | Instagram audio id of the sound; pass it to instagram.audio_reels as audioId to list other reels using it. Null when the media has no sound or this source does not report it. |
| `data.avatarUrl` | string | no | Profile picture URL of the posting account. |
| `data.bytes` | integer | no | Size of the hosted MP4 in bytes. Present only when the request set `hostVideo` to true. |
| `data.caption` | string | no | Caption text of the post, including its hashtags and @mentions. Empty when the post has no caption. |
| `data.comments` | integer | no | Number of comments on the post. |
| `data.countsHidden` | boolean or null | no | Whether the author has hidden the like and view counts. Null when this source does not report it. |
| `data.createdUtc` | number | no | UTC epoch timestamp in seconds (Unix time). Multiply by 1000 for a JS Date in milliseconds. |
| `data.displayName` | string | no | Display name of the posting account. |
| `data.displayUrl` | string | yes |  |
| `data.durationSeconds` | number or null | no | Video duration in seconds. Null on a photo, or when this source does not report it. |
| `data.expiresUtc` | integer | no | When `hostedUrl` stops working, as a UTC epoch timestamp in seconds (Unix time). Multiply by 1000 for a JS Date in milliseconds. Present only when the request set `hostVideo` to true. |
| `data.hasAudio` | boolean | no | True when the media carries an audio track. |
| `data.hashtags` | array | no | Hashtags carried in the caption, each including its leading #. Empty when the caption uses none. |
| `data.hostedUrl` | string | no | AnyAPI-hosted MP4 of this post's video, playable without an Instagram session. Present only when the request set `hostVideo` to true. |
| `data.id` | string | yes |  |
| `data.likes` | integer | yes |  |
| `data.locationId` | string | no | Instagram id of the tagged place, when the post tags one. |
| `data.locationLat` | number or null | no | Latitude of the tagged location, in decimal degrees. Null when the post tags no place or this source does not report it. |
| `data.locationLng` | number or null | no | Longitude of the tagged location, in decimal degrees. Null when the post tags no place or this source does not report it. |
| `data.locationName` | string | no | Name of the tagged place, when the post tags one. |
| `data.mentions` | array | no | Accounts mentioned in the caption, each including its leading @, in caption order. Empty when the caption mentions none. |
| `data.owner` | string | yes |  |
| `data.paidPartnership` | boolean | no | True when the post is tagged as a paid partnership. |
| `data.plays` | integer | no | Number of plays of the reel or video. Absent when Instagram does not expose a play count for this media, and on lanes that cannot serve it. |
| `data.productType` | string | no | Instagram product type of the media, for example feed, clips or igtv. |
| `data.reshares` | integer or null | no | Number of times the post has been reshared. Null when this source does not report it. |
| `data.shortcode` | string | yes |  |
| `data.soundAuthor` | string or null | no | Credited author of the sound. Null when the media has no sound or this source does not report it. |
| `data.soundTitle` | string or null | no | Name of the sound. "Original audio" means the creator's own audio rather than a licensed track. Null when the media has no sound or this source does not report it. |
| `data.type` | string | yes |  |
| `data.userId` | string | no | Instagram user id of the posting account. |
| `data.verified` | boolean | no | True when the posting account carries a verified badge. |
| `data.videoUrl` | string | yes |  |
| `found` | boolean | yes |  |

Extra fields are kept, missing declared fields fail.

## Fields that must never come back empty

- `caption`
- `displayUrl`
- `hashtags`
- `id`
- `owner`

The repository marks these fields as ones every source must be able to fill. An empty value is only correct when the entity itself genuinely has nothing there.

## Not found, and how it differs from empty

When the entity does not exist, answer 2xx with the not-found shape:

```json
{
  "found": false,
  "data": null
}
```

An empty list is not a not-found: when the entity exists and has nothing to return, answer 2xx with `found: true` and an empty `hashtags` array.

This output schema declares no `reason` field, so `found: false` is the whole not-found answer.
