Search TikTok Creative Center top video ads by keyword, with campaign objective, performance percentile, and time-window filters.

This page is the seller-facing summary of one catalog API, `tiktok.top_ads_search`. The transport rules that apply to every API a seller serves - signed requests, the response envelope, timeouts, and body limits - are on [the operator endpoint contract](/sell/operator-endpoint-contract).

## The price you compete with

AnyAPI publishes this API from **$1.20 per 1,000 requests**. That is the price a buyer sees today, so it is the price your endpoint has to come in under to win traffic.

## The request your endpoint receives

| Field | Type | Required | What it means |
| --- | --- | --- | --- |
| `limit` | integer | no | Maximum number of ads requested for this page, from 1 through 20 (default 20). Default `20`. |
| `objective` | string | no | Campaign objective filter. Omit it to search every objective. One of: `traffic`, `app_installs`, `conversions`, `video_views`, `reach`, `lead_generation`, `product_sales`. |
| `page` | integer | no | One-based provider page number (default 1). Default `1`. |
| `performanceRank` | string | no | Ad performance percentile bucket, where top_1_20 is the highest-performing 20 percent. Omit it to search every bucket. One of: `top_1_20`, `top_21_40`, `top_41_60`, `top_61_80`. |
| `period` | integer | no | Lookback period in days (default 180). One of: `7`, `30`, `180`. Default `180`. |
| `query` | string | yes | Keyword to search in TikTok Creative Center top video ads. |

## The response your endpoint must return

| Field | Type | Always present | What it means |
| --- | --- | --- | --- |
| `data` | null or object | yes | Top-ad results and page metadata, or null when no matching ads were found. |
| `data.ads` | array | yes | TikTok Creative Center top-ad records returned for this page. |
| `data.ads[].adId` | string | yes | TikTok Creative Center ad material identifier. |
| `data.ads[].adTitle` | string | no | Title or primary copy shown for the ad. |
| `data.ads[].brandName` | string | no | Advertiser brand name when supplied by TikTok Creative Center. |
| `data.ads[].cost` | number | no | TikTok Creative Center's relative cost ranking value for the ad. |
| `data.ads[].ctr` | number | no | TikTok Creative Center's click-through rate value for the ad. |
| `data.ads[].durationSeconds` | number | no | Video duration in seconds. |
| `data.ads[].height` | integer | no | Video height in pixels. |
| `data.ads[].image` | string | no | Signed video cover image URL exactly as returned by TikTok Creative Center. |
| `data.ads[].industry` | string | no | TikTok Creative Center industry classification key. |
| `data.ads[].likes` | integer | no | Number of likes reported for the ad. |
| `data.ads[].objective` | string | no | TikTok Creative Center campaign objective key. |
| `data.ads[].videoUrl` | string | no | Signed 720p video asset URL exactly as returned by TikTok Creative Center. |
| `data.ads[].width` | integer | no | Video width in pixels. |
| `data.hasMore` | boolean | yes | Whether TikTok Creative Center reports another page of matching ads. |
| `data.page` | integer | yes | One-based page number reported by TikTok Creative Center. |
| `data.pageSize` | integer | yes | Page size reported by TikTok Creative Center. |
| `data.total` | integer | yes | Total number of matching top ads reported by TikTok Creative Center. |
| `found` | boolean | yes | True when TikTok Creative Center returned at least one matching top ad. |

Extra fields are kept, missing declared fields fail.

The repository marks these fields as ones every source must be able to fill. An empty value is only correct when the entity itself genuinely has nothing there.

## Not found, and how it differs from empty

When the entity does not exist, answer 2xx with the not-found shape:

```json
{
  "found": false,
  "data": null
}
```

An empty list is not a not-found: when the entity exists and has nothing to return, answer 2xx with `found: true` and an empty `ads` array.

This output schema declares no `reason` field, so `found: false` is the whole not-found answer.
