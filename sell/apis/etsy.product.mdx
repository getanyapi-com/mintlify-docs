Look up one Etsy listing by id and get its price, images, description, rating, reviews count, shop, category, variations, stock, ship-from country, favorites and materials in one normalized response.

This page is the seller-facing summary of one catalog API, `etsy.product`. The transport rules that apply to every API a seller serves - signed requests, the response envelope, timeouts, and body limits - are on [the operator endpoint contract](/sell/operator-endpoint-contract).

## The price you compete with

AnyAPI publishes this API from **$1.87 per 1,000 requests**. That is the price a buyer sees today, so it is the price your endpoint has to come in under to win traffic.

## The request your endpoint receives

| Field | Type | Required | What it means |
| --- | --- | --- | --- |
| `listingId` | string | yes | Etsy listing id, the number in the listing URL (https://www.etsy.com/listing/&lt;id&gt;/...), e.g. 1810545592. The Etsy Search and Etsy Shop Listings SKUs return it as listingId. |
| `requireFields` | array | no | Optional; omit it and routing is unchanged, with the cheapest source serving. Name the output fields this request must be able to return, for example `materials`, and it is served only by a source that returns every one of them. Fields you do not name are still returned whenever the serving source has them. This can raise your price: when the cheapest source cannot return a named field, a dearer source serves, and you are quoted and charged its price. Naming a combination that no single source returns together is refused as invalid input, with no charge. |

## The response your endpoint must return

| Field | Type | Always present | What it means |
| --- | --- | --- | --- |
| `data` | null or object | yes | Listing wrapper, or null when Etsy has no available listing with that id. |
| `data.items` | array | yes | Listing detail records (one per requested listing id). |
| `data.items[].category` | string or null | no | Etsy category trail from top level down, joined with " &gt; ", e.g. "Jewelry &gt; Necklaces &gt; Monogram & Name Necklaces", or null when not reported. |
| `data.items[].currency` | string or null | no | Price currency code, e.g. "USD", or null when no price is shown. |
| `data.items[].description` | string or null | no | The seller's listing description, or null when not reported. |
| `data.items[].favoriteCount` | integer or null | no | Number of shoppers who favorited the listing, or null when the serving source does not report it. |
| `data.items[].images` | array | no | Listing image URLs, primary first. |
| `data.items[].listingId` | string | yes | Etsy listing id. |
| `data.items[].materials` | array or null | no | Materials the seller lists, e.g. ["14k/Yellow Gold/Pearl"], or null when the serving source does not report them. |
| `data.items[].price` | number or null | no | Current price in the listing currency (the lowest variation price when the listing shows a range), or null when not shown. |
| `data.items[].quantityAvailable` | integer or null | no | Units in stock, or null when the serving source does not report it. |
| `data.items[].rating` | number or null | no | Average rating, 0-5, or null when the listing is unrated. |
| `data.items[].reviewsCount` | integer or null | no | Number of reviews, or null when not reported. |
| `data.items[].shipFrom` | string or null | no | Country the listing ships from as a 2-letter ISO code, e.g. "US", or null when not reported. |
| `data.items[].shopId` | string or null | yes | Etsy id of the shop selling the listing, or null when not reported. |
| `data.items[].shopName` | string or null | no | Name of the shop selling the listing; pass it to the Etsy Shop SKU. Null when not reported. |
| `data.items[].title` | string | yes | Listing title. |
| `data.items[].url` | string | yes | Etsy listing page URL with tracking query parameters removed. |
| `data.items[].variations` | array | no | The choices a buyer picks from, e.g. Finish and Length, each with its values. Empty when the listing has none. |
| `data.items[].variations[].name` | string or null | no | Variation name as the seller lists it, e.g. "Length", or null when the serving source does not report it. |
| `data.items[].variations[].values` | array | no | Values a buyer can pick, as Etsy labels them, e.g. ["14 inches ($29.25)", "16 inches ($29.25)"]. |
| `data.items[].video` | string or null | no | Listing video URL (MP4), or null when the listing has none or the serving source does not report it. |
| `found` | boolean | yes | True when the listing was found. |

Extra fields are kept, missing declared fields fail.

## Fields that must never come back empty

- `category`
- `currency`
- `description`
- `images`
- `items`
- `listingId`
- `price`
- `rating`
- `reviewsCount`
- `shopName`
- `title`
- `variations`

The repository marks these fields as ones every source must be able to fill. An empty value is only correct when the entity itself genuinely has nothing there.

## Not found, and how it differs from empty

When the entity does not exist, answer 2xx with the not-found shape:

```json
{
  "found": false,
  "data": null
}
```

An empty list is not a not-found: when the entity exists and has nothing to return, answer 2xx with `found: true` and an empty `items` array.

This output schema declares no `reason` field, so `found: false` is the whole not-found answer.

## Example request

```json
{
  "listingId": "1810545592"
}
```

The registration tests send this example to your endpoint, with the API's other test inputs. After that, your answers are graded against what the currently serving source returned for the same real customer inputs.
